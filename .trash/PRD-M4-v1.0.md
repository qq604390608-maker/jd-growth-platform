## 1. 模块目标与定位

M4 是第二阶段研究 Agent：围绕产品研究问题深入分析——人群比较、候选行为寻找与检验、其他解释查证、结果整理。HVA＝可能与用户长期价值有关、值得进一步研究的关键行为；**研究完成前都属于候选行为**。本模块产出完整研究报告（七要素），允许"未找到足够依据支持候选 HVA"也是完整结果。

## 1.1 领域能力定义（agent.md · business-rules.md · Skill 清单）

> 本模块的运行期领域能力由三部分构成：**角色指令（agent.md）**定义"你是谁"、**公共业务指令（business-rules.md）**是两 Agent 共用的行为边界、**Skill 清单**是 Agent 可调用的能力单元（每个 Skill 对应 §3 的一个或多个功能点）。来源文件：`agent.md`（HVA 分析 Agent 角色段）、`business-rules.md`（公共业务指令）、Skill 注册见 `MD-14 skill_registry`（S-B1~S-B4，Q-07 已决：S-B1＝`hva-five-checks`）。

### 1.1.1 角色指令（agent.md · HVA 分析 Agent）

- **职责**：京东超市 HVA 分析研究员，围绕产品研究问题研究人群与候选行为。
- **输入**：所选机会及版本、产品研究问题（＋可选候选行为假设、人群限制）、业务目标与口径、已有证据、相关历史研究。
- **工作方式**：判断问题是否适合 HVA 研究 → 有假设则查证假设、无假设则寻找候选行为 → 人群比较五查（可比基础 / 先后关系 / 口径对应 / 其他解释 / 信息充分）→ 比较条件随分析保存。
- **输出**：研究结果（七要素），每项关键发现关联证据；或说明问题、已有发现与 HVA 判断限制。
- **结束条件**：形成有依据的研究回答，或说明无法完成判断的原因。产品假设不预先作为研究结论。

### 1.1.2 公共业务指令（business-rules.md · 两 Agent 共用）

> 作为公共业务指令由运行程序（M1）加载，机会发现 Agent 与 HVA 分析 Agent 共同遵守。

- 关键发现需要关联实际取得的证据；
- 初步解释、产品假设与研究判断分别标明性质；
- 业务范围、证据要求、信息使用边界和输出原则；
- 查询必须经工具执行程序，禁止以模型预期内容代替查询结果；权限不足或失败时保留原因并说明受限；
- 引用任何证据必须带来源系统、查询条件、信息时点与适用范围——作为公共业务指令由运行程序加载，两 Agent 共同遵守；
- 不替业务方定义指标口径；口径不清时列出待补项；
- 研究输出止于"有依据的判断＋限制＋改善方向"，不输出活动配置、权益组合、预算与排期；
- 不调用任何面向生产环境的写接口（硬红线）。

## 2. 范围

**In scope**：F-18~F-22（角色指令配置、研究起点处理、人群比较与行为关系检验、研究结果生成、继续追问承接）。
**Out of scope**：机会发现（M3）、查询执行（M5）、前端展示（M6）、目标与任务调度（M1，F-04 触发本模块）。

## 3. 功能需求

### F-18 角色指令配置

- **功能描述**（继承 BRD §4）：agent.md 定义第二阶段职责、输入、输出与结束条件。
- **输入 → 输出**：— → agent.md（hva-agent）。
- **验收要点**：结束条件——形成有依据的研究回答 / 说明无法完成判断的原因。
- **关联 schema**：`MD-13 agent_profile`（`agent_code=AGP-HVA`）、`MD-14 skill_registry`（Skill 登记，Q-07 裁决前建表不种）。
- **关联技术栈**：推理来源＝Workers AI（DS-02）。
- **依赖与衔接**：被 M1 F-04 在 HVA 任务中加载。

### F-19 研究起点处理

- **功能描述**（继承 BRD §4）：先判断问题是否适合开展 HVA 研究。三种起点：① PM 提供候选行为假设 → 检查假设对应的人群、行为与结果（**产品假设不预先作为研究结论**）；② 只有研究问题 → 根据问题与可获得的行为信息寻找候选行为再比较查证（**允许找不到有足够依据的候选行为**）；③ 问题不适合或缺少关键行为依据 → 说明问题、已有发现与 HVA 判断限制（如问题主要涉及服务体验，只说明障碍及改善方向，不硬归结为关键行为）。
- **输入 → 输出**：产品研究问题 → 研究路径选择。
- **验收要点**：三种起点的分支与保留判断。
- **关联 schema**：`MD-12 research_proposal`（输入：机会版本＋研究问题＋可选假设/人群限制）。
- **依赖与衔接**：上游＝M1 F-03/F-04（研究建议→HVA 任务）。

### F-20 人群比较与行为关系检验

- **功能描述**（继承 BRD §4）：候选行为五查：① 人群是否有可比基础（原有特征与表现差别未解释时，限制行为作用判断）；② 行为与结果的先后关系（行为须发生在所讨论的后续表现之前，不能把已发生的结果当行为影响）；③ 结果是否对应业务目标（口径一致）；④ 是否存在其他解释（商品、活动、权益等业务条件）；⑤ 信息是否足以支持判断（缺关键依据时说明缺口，不给确定判断）。比较条件（涉及哪些用户、观察哪个阶段、什么结果口径）随分析保存。
- **输入 → 输出**：候选行为＋人群 → 比较结果＋限制说明。
- **验收要点**：观察到行为与较好表现同时出现 ≠ 因果；某活动存在只证明有活动信息，用户是否参与、受何影响需对应记录。
- **关联 schema**：`MD-09 candidate_behavior`（候选行为）、`MD-10 behavior_point`（候选行为支持情况条目，逐条对应五查）、`CFG-05 gap_rule`（五查口径）。
- **关联外部依赖**：数据源＝CDP（人群可比性）、HJE（行为）、PIM（商品条件）、MKT（权益条件）（§1 F-20 行）；P0 阻断＝CDP/黄金眼，P1 削弱＝商品中台/营销中台，P2 降级＝活动报名系统（§2 分级）；TOL-03/TOL-10 能力不足的缺口来源（§5 脚注）。
- **依赖与衔接**：查询经 M5；缺口如实登记，影响结论限制说明。

### F-21 研究结果生成

- **功能描述**（继承 BRD §4）：七要素组装：业务目标与研究问题 / 研究范围与方法 / 证据与关键发现 / 人群差异 / 候选 HVA 及支持情况 / 其他解释与限制 / 改善方向。每项关键发现关联实际取得的证据；**未找到足够依据支持候选 HVA 也可形成完整结果**；改善方向与发现逐项对应（针对什么人群、什么问题、为什么值得改善），活动配置、权益组合、预算与排期不在其内。
- **输入 → 输出**：比较结果 → 完整研究报告。
- **验收要点**：读者能分清"已查明的内容"与"仍存在的限制"；查询失败导致的未完成不能当否定依据。
- **关联 schema**：`MD-07 research`（研究主体，七要素）、`MD-08 research_finding`（关键发现，挂证据）、`MD-09 candidate_behavior`、`MD-10 behavior_point`（支持/不支持并列）、`MD-11 improvement_action`（改善方向，与发现逐项对应）、`LNK-02 finding_evidence`（关键发现↔证据）。
- **依赖与衔接**：供 M6 F-30 展示；供 M1 F-05 追问派生。

### F-22 继续追问承接

- **功能描述**（继承 BRD §4）：PM 需要继续查证时在已有研究上提新问题；Agent 检查已有依据是否仍适用（时间范围、查询条件变化时补查），再决定沿用或补查。
- **输入 → 输出**：新问题＋原研究 → 新一轮结果。
- **验收要点**：追问形成新任务但保留原结果与依据（见 F-05）。
- **关联 schema**：`PD-07 followup_message`（追问对话消息）、`PD-01 task`（`parent_task_id` 关联原任务）、`MD-02 research_goal_version`（范围变更落新版本）。
- **依赖与衔接**：上游＝M1 F-05；再触发本模块 F-19/F-20/F-21。

## 4. 关键约束与红线

1. **候选行为不提前定性**：HVA 在研究完成前一律称"候选行为"（BRD §6 术语口径）。
2. **假设不预先当结论**：PM 提供的候选行为假设须被检验，不预置为结论（F-19 ①）。
3. **因果不臆断**：行为与较好表现同时出现 ≠ 因果；活动存在 ≠ 用户参与（F-20 ②③④）。
4. **失败不否定结论**：查询失败导致的未完成不能当否定候选 HVA 的依据（BRD §7 第 4 条）。
5. **改善方向不越界**：活动配置、权益组合、预算与排期不在本模块（BRD §5.2 out of scope）。
6. **白盒原则**：F-18~F-22 逐点验收、双向引用。

## 5. 验收总则（模块级，承接 BRD §7）

- 七要素齐全；关键发现逐项挂证据；已查明与仍受限视觉/文本可分。
- 五查逐条有结论与限制说明；缺失关键依据时标注缺口。未支持候选 HVA 也是完整结果。
