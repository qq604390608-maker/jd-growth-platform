## 1. 文档定位

本文件是 PRD 体系的**树干级索引**：只列出六大模块与对应子 PRD 的进入点、全局范围与约定，以及本套 PRD 与上游/下游的引用关系。**所有实现细节、功能需求、验收要点、表/工具映射均下沉到子 PRD-M1~M6 与三项锁定，不在本文件展开。**

需求全量来自 `../01-brd/BRD.md`；字段口径以 `../03-locks/schema.md` 为准；外部依赖以 `../03-locks/external-deps.md` 为准；技术选型以 `../03-locks/tech-stack.md` 为准。
