## 硬纪律（不可绕过）

- **一 F-xx 一 PR**：开工前读上游真源（子 PRD 验收要点 → `docs/05-test-cases/test-Mx.md` 的 oracle → `docs/03-locks/*` → `AGENTS.md` 红线）；交付走**双向登记**（文档卡 + 反向清单 + 目录 README + `AGENTS.md` 状态位 + `ci.yml` 一步）。
- **四条红线**：生产零写 / 真实返回 / 证据四要素 / 失败不否定结论——写进每份产物，且**尽量做成可静态扫描或可运行期断言**的判据，不靠人工保证。
- **外部依赖门禁**：`external-deps.md` §7 未关项未关时，外部调用一律 mock/demo，**demo 数值不进断言**；未关项对应的用例不设为发布门禁。⚠️ 统计未关要**两种标记都算**——除 `⬜ 正文留空`，**带 `*` 的 demo 占位同样是未关闭**（实测 11 条 vs 真实 16 条）。demo 占位＝「假性就绪」，比空白更危险：链路跑得通，容易被误认为已就绪。
- **发现上游文件自身缺陷 → 先登记「未擅自改」，等用户点头再动**；动手时按全套流程（bump 版本 + 旧版进 `.trash/` + 比对 SHA + 同步下游钉版）。口径不确定的**登记成 Q-xx 挂 `docs/03-locks/schema.md` §12**，并明确「当前按哪个方向实现」。
- **未决项不只挂三张清单，ADR 也会内嵌**：按 `⬜|⏳|待确认|待裁决` **全仓扫**（含 `docs/07-decisions/`），优先看那些「写明必须在某动作前关闭」的项——最容易变成已敞口却无人发现的缺口。

## 架构约定

**写面拆分**
- **新增写面就单独成文件**。例：`tool-executor/` 的 `mcp-client.js`（传输层，零 SQL 零写）、`task-state.js`（任务态写入面，改行只落 `task` 且带主键条件）→ `index.js` 保持「不含改行 / 删行类 SQL」，**既有 `test-f23.mjs` 零写断言永不用改**。这个拆法的第一目的就是**扩写面时不动既有 oracle**。
- **一个模块可以有多个写面**（`agent-orchestrator/`：`profile.js` 管 MD-13/14、`behavior-store.js` 管 MD-09/10）；编排文件（`role.js`/`behavior.js`）**零写语句零裸 SQL**，取号也不写 `SELECT MAX`（用读面返回的全量自算「库内最大 +1」）。模块级硬红线那句「本目录只写 X 表」是**清单**、不是「只有一张表」，新增写面必须同改该句。
- **引入同目录内新 import 会改变「文件间引用图」**：目录 README 的「文件间引用」段逐文件写明「谁被别人 import」，必须同改；否则文档与现实不符（交付自检最易漏项）。
- **纯读面编排器范式**：跨模块**可新增只读面**，但**绝不新增跨模块写面**；模块硬红线要同补该只读面并写明「本模块仍不含跨模块写动作」。

**派生与真源**
- **派生优于复制**：上游有真源常量就用 `map` 派生，并在用例里断言 `派生.join(">") === 上游常量.join(">")`——改一处不可能漏，且「不复制第二个口径」变成可静态核对的断言。
- **值域一律从库读、不内联**：`dict_item` 是唯一真源（`dictCodes(db,'TASK_STATUS')` 等），代码里不复制中文枚举。
- **叙述文本本体只存 `agent-runtime/` 一份**：服务端只持「编号 + 判据键 + 来源回指」，用例逐条对齐断言（读本体 md 抽标题列表 vs 代码常量列表，逐条相等）；常量标题须与本体标题**逐字一致**（修饰语放正文），否则「回指不重述」退化成第二个口径。
- **派生数据只能引用「已应用版本」的口径**（2026-09-21）：机会的 `initial_basis_note` / `query_condition`、证据的 `query_condition`，凡声明「由目标配置逐字派生」的，**只能取 `goal_version.is_applied = 1` 那一版**。实测 `GOAL-2026Q3-01` 的 v2（`is_applied=0`，GAP-001 补充版）含「；单品首单不计入」而 v3 不含 → 8 处写错版本，第二次 OPS 才改回。**写任何派生串之前先读 `current_version`**，别读 `versions[]` 里任意一版。校验手法：正则抽出全部条件 → **去重** → 与「线上 `current_version` 四要素重拼串」做**全等**比对（不用「包含」），并断言旧写法残留 0。

**范式（后续功能点沿用）**
- **约定优于重写 oracle**：断言能不动就不动；确需扩写面时优先改架构（拆文件 / 缩窄写面），其次才是改用例。
- **「应用层判缺」用「库级放行」做反例**：库级拦不住时（`NOT NULL` 拦不住纯空白串、`CHECK(x>=1)` 放行 `''`），先证**库级放行**（把那行真插进去）再证**应用层判缺**，并把「不会被误标为合格」也断上。
- **受门禁的语义判断＝可注入判据 + 确定性 fallback**（F-19 范式）：需 LLM（A-1）的那步**不做关键词猜测**——可选入参传了就采纳（`source='provided'`），没传走**确定性 fallback** 并显式标 `llm_gated=true`；入参非法一律报错、不静默忽略。门禁开闭**同一套代码**可用，oracle 三分支在门禁期内即可走通。
- **「缺信息」≠「路径未定」**：能定则定、缺则如实登记（列入 `missing`，不编造、不静默回退），**但不阻断本步的停止条件**；补齐动作交给下游功能点。别把上游的缺口变成自己的失败。
- **建行与内容填充可分属两个功能点**：`MD-07` 建行归 F-11（含启动快照与追问链字段）、内容填充归 F-21（**只改 6 个正文/状态列 + `finished_at`**）→「出报告」在结构上不可能改动启动快照与追问链。配套：**承载红线文案的字段不参与禁词扫描**，但须放**豁免反例**（禁词进正文仍须被拒），防止豁免退化成「整表不扫」。
- **「门禁态」与「空态」刻意分开**：前置动作没做＝**门禁**（整块收起、指回去执行）；进来了但本轮无产出＝**空态**，且要点明上游口径（如 M3-F-16「依据不足也是合法产出」≠「没有机会」）。两者用不同夹具各自走通，不共用一个「无数据」分支。
- **「未决 ≠ 沿用」**：判定是否复用既有依据时，未声明变更 / 无法判定一律落**中间态**并标 `llm_gated`（既不沿用也不补查）；只有「明确声明且可客观比对」才给沿用 / 补查的确定结论。**保守方向优先**（适用范围更窄沿用；更宽或抽不到时点一律补查）。
- **「事实行优于状态列」**：判「某前置动作是否真的发生过」一律落在事实表上——**看子表/事实表有没有那一行，不读状态列**（可能被旁路写脏或与事实不符）。实测：种子把 `OPP-010`/`OPP-012` 标成 `submitted` 但 `research_proposal` 无对应行；M1-F-17 的完成判据本就写「以 MD-12 有无真实建议行为准」（不看机会状态）。做法：把这条反例写成**用例主断言**（「状态为 submitted 但无建议行 → 不得谎报已提交」）。同类：判任务是否真跑过看 `task` 行，不看目标状态位。

**前端（`frontend/`，零构建）**
- 全站**唯一网络出口是 `assets/api.js`**（静态断言「只有它出现 `fetch`」）+ **运行期守卫**（路径必须 `/api/` 开头、不得含 `://`，违反直接抛错不发请求；`BASE` 恒空串）。纪律做成闸，不靠注释。
- 业务数据只在服务端，`localStorage` 只存会话态（`applied`/`navUnread`）并有用例实测存储键；六要素键序一律取服务端 `GOAL_FIELDS` / `OPPORTUNITY_SIX_ELEMENTS`，**口径副本逐条对齐上游常量**（用例逐字比对）；**看页面不写库**（进入即 GET-only，写只由显式按钮或「保存后自动跑一次」触发）；**不自造端点**（缺接口登记 `frontend/README.md` §4）；**「可回查」必须走上游回查路由**（`GET /api/evidence-trace/{id}`，前端不自己拼）；**写请求白名单**——用例断言写请求**只**落本功能点该用的路由，且不出现 `/api/query|query-records|query-recovery|tool-permission|agent-delegations`。
- **前端不复制第二份校验口径**（规则在服务端时）：页面调服务端检查接口并原样呈现 `missing[]`/`hint`；用例**静态断言页面不出现那份规则的正则字面与阈值**（判据用**正则字面**而非单个词，因为原型钉死的 placeholder 里出现「搜索/人群」这类词是允许的），并加「不误报」反例。
- **前端用例缺依赖要显式失败**：`require("jsdom")` 失败须**打印安装命令并 `exit(1)`**——前端用例被跳过＝一条无人看守的静默洞。
