# MEMORY.md · 京东-agent项目（长期项目约定）

> 只记**跨会话仍成立**的约定与结论。**细则/实测/反例一律在 `PITFALLS.md`**（断言与静态扫描、写面与状态、种子与版本、并发与数据形态、工具与文档流程），本文件每条只留结论句 + 指向。

## 硬纪律（不可绕过）

- **一 F-xx 一 PR**：开工前读上游真源（子 PRD 验收要点 → `docs/05-test-cases/test-Mx.md` oracle → `docs/03-locks/*` → `AGENTS.md` 红线）；交付走**双向登记**（文档卡 + 反向清单 + 目录 README + `AGENTS.md` 状态位 + `ci.yml` 一步）。
- **四条红线**：生产零写 / 真实返回 / 证据四要素 / 失败不否定结论——**尽量做成可静态扫描或运行期断言**，不靠人工保证。
- **外部依赖门禁**：`external-deps.md` §7 未关项 → 外部调用一律 mock/demo，**demo 数值不进断言**。⚠️ 统计未关要**两种标记都算**：`⬜ 正文留空` 与**带 `*` 的 demo 占位**（后者＝「假性就绪」，比空白更危险）。
- **发现上游文件自身缺陷 → 先登记「未擅自改」，等用户点头再动**；动手走全套（bump 版本 + 旧版进 `.trash/` + 比对 SHA + 同步下游钉版）。口径不定 → 登记 Q-xx 挂 `schema.md` §12 并写明当前方向。
- **改索引/宪法类文档时，连带项是「钉了行号/版本的下游引用」**：grep 两路 `文件[^]{0,40}L[0-9]`（行号）与 `文件.*v[0-9]`（版本）；行号引用一律改成**条目名引用**，ADR 里的旧版本号属**时点留档**不改。**索引类文件的状态列只写「状态 + 差额 + 指向真源」**，逐点明细留给下游真源（否则就是第二份副本，且必与「不写成全量清单」自相矛盾）。量化信号：**单行字符数占全文比**。
- **未决项会散落在三张清单之外（ADR 也内嵌）**：按 `⬜|⏳|待确认|待裁决` **全仓扫**（含 `docs/07-decisions/`），优先看「写明必须在某动作前关闭」的项。

## 架构约定

**写面拆分**
- **新增写面单独成文件**（`task-state.js` / `mcp-client.js` 范式）→ 编排文件保持「不含改行/删行 SQL」，**扩写面时不动既有 oracle**（`test-f23` 零写断言永不用改）。
- **一个模块可有多个写面**；红线句「本目录只写 X 表」是**清单**不是「只有一张表」，新增写面必须同改。
- **同目录新 import 会改「文件间引用图」** → 目录 README「文件间引用」段必须同改（交付自检最易漏）。
- **纯读面编排器范式**：跨模块**可加只读面，绝不新增跨模块写面**，红线句要同补。

**派生与真源**
- **派生优于复制**：有真源常量就 `map` 派生，并断言 `派生.join(">") === 上游常量.join(">")`。
- **分派/选取类常量唯一真源**：`WIRED_TASK_TYPES`、`TICK_PHASES`、`RESEARCH_STEP_COUNT`（派生自 `TYPE_STEPS`）、号形态与命名空间——新增一类只改一处，别处不再写 `=== "xxx"`。
- **值域一律从库读**（`dictCodes(db,'TASK_STATUS')`），不内联中文枚举。
- **叙述文本本体只存 `agent-runtime/` 一份**，服务端只持「编号 + 判据键 + 回指」；常量标题须与本体标题**逐字一致**。
- **派生串只能引用「已应用版本」口径**：声明「由目标配置逐字派生」的字段（机会 `initial_basis_note`/`query_condition`、证据 `query_condition`）**只能取 `is_applied=1` 那版**（先读 `current_version`）。校验：正则抽条件 → 去重 → 与线上重拼串**全等**比对。

**范式（后续沿用，细则见 PITFALLS.md）**
- **约定优于重写 oracle**：断言能不动就不动；需扩写面时先改架构，其次才改用例。**新分支并进旧语句，不加第二条 SQL**（F-37）。
- **「应用层判缺」用「库级放行」做反例**：先证库级放行，再证应用层判缺，并断「不会被误标合格」。
- **受门禁的语义判断＝可注入判据 + 确定性 fallback**（F-19）：不做关键词猜测；入参非法**抛错**不静默；fallback 显式标 `llm_gated=true`；门禁开闭同一套代码。
- **「缺信息」≠「路径未定」**：能定则定、缺则登记 `missing`，**不阻断本步停止条件**。
- **建行 vs 内容填充可分属两个功能点**（MD-07 建行 F-11 / 填充 F-21 只改 6 列 + `finished_at`）。配套：承载红线文案的字段**不参与禁词扫描**但须放**豁免反例**。
- **「门禁态」与「空态」刻意分开**（各自夹具走通，不共用「无数据」分支）。
- **「未决 ≠ 沿用」**：未声明变更 → 中间态 + `llm_gated`；**保守方向优先**（更宽一律补查）。
- **「调用方写错」≠「任务受阻」**：`catch` 只收结构性受阻；程序性错误（越界步号/入参形态非法/类型不符）在 `try` **外**抛错。断言三件：抛对文案 + 步态未改 + `task_block` 为 0。
- **多相位 tick**：相位级 try/catch + 顺序做**导出常量**并断言；**保留原顺序、不顺手重排**（同 tick 流水线）；失败相位返回**键齐空形态**；失败必留痕（`why` 逐字带 message + 可注入 `onError`）。「不缺键」与「不静默」都要。
- **改「锁定件」前先评估三件事**（DDL 是否单文件 / 有无「N 张表」总量声明 / 总量散落几处），**范围口径未定就登记待裁决、不开工**；只改本项被授权的锁定件，过期交叉引用登记不擅动，优先用「N 业务 + M 基础设施」拆分声明缩小改动面。
- **「事实行优于状态列」**：判前置动作是否真发生过，看**事实表有没有那一行**，不读状态列（种子有 `submitted` 但无 `research_proposal` 行的机会）→ 写成用例主断言。
- **「清空残留值」走显式清空口，不改写入方**（F-37）：开关 `clear_ended_at` 作唯一清空口，实现并进原有 `CASE` 语句；**必须配反例断言**「未显式声明时旧值仍保留」。
- **过滤「不可用项」要逐条收窄**（F-38）：只丢整块不够——计划某步的 `data_sources` 要**逐个来源收窄**，排除项如实登记并进 `done_part`；既有「`[]`＝不过滤」语义由调用方**显式开启**（`allowEmpty`），未注入时行为逐字不变；可用来源**现读** M5 `listTools({is_enabled:1})`。
- **取号原子化（F-35）**：一条 `UPDATE id_sequence SET next_val=next_val+1 … RETURNING` 完成「自增+取值」，取代读后写；原子性要有实证（官方说明 + 本地探针），不靠类推。冷路径必传「既有编号清单」缺则抛错，热路径绝不回读业务表；漂移修复单独成显式动作（只抬不降、幂等）；残余取号面登记待办（15 个函数 / 4 模块，已收敛最热 3 条）。

**前端（`frontend/`，零构建）**
- 全站**唯一网络出口 `assets/api.js`**（静态断言只有它出现 `fetch`）+ 运行期守卫（`/api/` 开头、不含 `://`、`BASE` 恒空串）。纪律做成闸。
- `localStorage` 只存会话态（`applied`/`navUnread`）；六要素键序取服务端 `GOAL_FIELDS`/`OPPORTUNITY_SIX_ELEMENTS` 并逐条对齐；**看页面不写库**；**不自造端点**（缺的登记 `frontend/README.md` §4）；回查只走 `GET /api/evidence-trace/{id}`；**写请求白名单**由用例断言。
- **前端不复制第二份校验口径**：调服务端检查接口原样呈现 `missing[]`/`hint`；静态断言页面不出现该规则的**正则字面与阈值**（不用单词，防 placeholder 误报）+「不误报」反例。
- **前端用例缺依赖要显式失败**（`require("jsdom")` 失败打印安装命令并 `exit(1)`）。
