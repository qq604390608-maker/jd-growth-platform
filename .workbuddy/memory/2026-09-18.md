## 22:45–23:59 · T-11 实测：D1 类型亲和与长度行为（探针 `/probes/type/`）

**任务**：实测 D1（SQLite）的类型亲和与长度行为，为 `tech-stack.md` §8 **T-11**（`varchar(n)` 兜底的策略选择）提供事实。**只实测、不预设结论**；禁止改 `schema.md`、禁止给全表加 CHECK、禁止污染业务 migration 目录。

**交付物**：`db/probes/type/README.md`（596 行）+ `schema.sql`(120) + `worker/index.js`(380) + `raw/*.json` 10 份（64,887 B）。另补 `db/probes/README.md`、`db/README.md` 打通引用链。

**手段**：复用 `db/probes/fk/` 的 worker 探针范式，跑**真实 miniflare D1**（wrangler 4.135.0，npx 缓存 `/Users/dongzhuo/.npm/_npx/32026684e21afda6/`）。**未用 sqlite3 代理**。共 148 条执行记录（成功 121 / 约束报错 27）。

**实测结论（关键 8 条）**：
1. `varchar(24)` 写 200 字符 → **不截断不报错**，读回 `length=200` 尾部完整，`typeof=text`。全部 `varchar(n)`（180 列）长度**一律不强制**。
2. **`datetime` 亲和类是 NUMERIC 不是 TEXT**：ISO 串落 text，但**纯数字串 / JS number 被转成 integer** → 同列混存储类（实测 10 text + 2 integer），混后 `ORDER BY` 与时间序**不一致**。
3. 零填充且归一到 UTC 的 ISO 串：**三组（跨时区/跨月/闰日）字符串序 == `julianday()` 序**；但**带偏移的本地串排序会反转**；**未零填充的串 `julianday()` 返回 NULL**。
4. `boolean` 亲和 NUMERIC；`true/false/TRUE` 与 JS `.bind(true/false)` **全落 integer 1/0**；`'true'` 落 text；**读回永不返回 JS boolean**；`tinyint` **不拦越界**（写 300 存 300）。
5. 空串 vs NULL **可区分**（`typeof` = `text` vs `null`）；`NOT NULL` **不拦空串**；`UNIQUE` **拦不住重复 NULL**（含 NULL 的复合键也不判重）。
6. 中文默认排序 = BINARY（码点序）：`张三,李四,王五`；独立参考 `Intl.Collator('zh-Hans-CN')` = `李四,王五,张三` → **不相等**。`COLLATE PINYIN`/`zh` 报 `no such collation sequence`。
7. `CHECK` 里 `length()`/`GLOB()`/`typeof()`/`length(cast(x AS blob))` **均可用且约束 UPDATE**；`length()` 按**字符**（24 中文=72 字节通过）、`cast AS blob` 按**字节**；`GLOB` **区分大小写**且前缀过宽（`F-01extra` 通过）。**`length(NULL)<=n` 放行 NULL，`typeof(NULL)='text'` 拒绝 NULL** —— NULL 行为取决于**表达式**而非 CHECK。多约束同时失败**只报声明顺序第一条**。
8. **`sqlite_version()` / `PRAGMA collation_list` / `PRAGMA compile_options` 被 D1 拒绝**（`D1_ERROR: not authorized`）→ D1 的 SQL 面被裁剪，无法用 PRAGMA 自证环境；`PRAGMA table_info` 可用且 declared type 原样可读。
